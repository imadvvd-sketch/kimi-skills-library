# محلل البيانات

## القدرات

- 📊 إنشاء رسوم بيانية (Bar, Line, Pie, Heatmap)
- 📈 حساب الإحصائيات الوصفية
- 🔍 استكشاف البيانات (EDA)
- 📋 توليد تقارير ملخصة
- 🧹 تنظيف البيانات

## سير العمل

### 1. تحميل البيانات
```python
import pandas as pd

df = pd.read_csv('data.csv')
# أو
# df = pd.read_excel('data.xlsx')
```

### 2. استكشاف البيانات
```python
# نظرة عامة
print(df.head())
print(df.info())
print(df.describe())

# القيم المفقودة
print(df.isnull().sum())
```

### 3. التحليل
- حساب المتوسط، الوسيط، الانحراف المعياري
- إيجاد الارتباطات
- تجميع البيانات (GroupBy)
- إنشاء الجداول المحورية (Pivot Tables)

### 4. التصور
```python
import matplotlib.pyplot as plt

plt.figure(figsize=(10, 6))
plt.bar(x, y)
plt.title('العنوان')
plt.xlabel('المحور X')
plt.ylabel('المحور Y')
plt.show()
```

## أنواع التحليل

| النوع | الاستخدام | الأدوات |
|-------|----------|---------|
| وصفي | ملخص البيانات | mean, median, std |
| تشخيصي | فهم الأسباب | correlation, root cause |
| تنبؤي | التنبؤ بالمستقبل | regression, time series |
| توصيفي | التوصيات | optimization, scenario |
