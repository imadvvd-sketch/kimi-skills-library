# LumaLab — محرر صور لأندرويد على طريقة Lightroom

LumaLab تطبيق أندرويد أصلي (Kotlin + Jetpack Compose) لتحرير الصور بشكل غير إتلافي. يقدّم نفس تجربة
**Adobe Lightroom Mobile** (`com.adobe.lrmobile`): مكتبة صور، أدوات إضاءة ولون وتأثيرات، منحنى درجات،
إعدادات مسبقة، قص وتدوير، وتصدير.

> **ملاحظة قانونية وعن المنهجية:** هذا **استنساخ للوظائف بأسلوب "الغرفة النظيفة"** (clean-room) وليس نسخًا لتطبيق Adobe.
> لم يُفكّك أي كود أو أصول خاصة بـ Adobe ولم يُنسخ منها شيء. أداة [REA](https://github.com/morluto/rea) نفسها تمنع في
> [إخلاء المسؤولية](https://github.com/morluto/rea/blob/main/DISCLAIMER.md) الخاص بها "نسخ البرمجيات المملوكة أو إعادة إنتاج
> كودها وأصولها المحمية". لذلك استُخدم منهج REA في "فهم الميزة ثم بناء نسخة خاصة بك": جُردت ميزات التطبيق من سلوكه
> المعلن وتوثيقه العام، ثم كُتب كل شيء (محرك المعالجة، الواجهة، الإعدادات المسبقة، الأيقونة) من الصفر. الاسم والهوية
> البصرية مختلفان عمدًا.

## الميزات

| القسم | ما يوفره LumaLab |
| --- | --- |
| **المكتبة** | استيراد عبر منتقي الصور في النظام أو المشاركة من تطبيقات أخرى، شبكة مصغّرات تعرض الصور **بعد التعديل**، تصفية (الكل / المختارة / المعدّلة / المقيّمة)، ألبومات، تحديد متعدد، حذف، **لصق الإعدادات على عدة صور دفعة واحدة** |
| **الإضاءة** | التعريض، التباين، الإضاءات، الظلال، الأبيض، الأسود، **منحنى درجات** (RGB والأحمر والأخضر والأزرق) |
| **اللون** | الحرارة، الصبغة، الحيوية (مع حماية لون البشرة)، التشبع، **مزج الألوان HSL** بثمانية نطاقات، **تدرج الألوان** (ظلال / متوسطة / إضاءات + مزج وتوازن)، أبيض وأسود |
| **التأثيرات** | الملمس، الوضوح، إزالة الضباب (dark-channel)، التظليل (نقطة المنتصف والتنعيم)، الحبيبات (مع الحجم) |
| **التفاصيل** | الحدة (مع نصف القطر)، تقليل تشويش السطوع وتشويش الألوان |
| **القص** | نسب جاهزة (حر، الأصلية، 1:1، 4:5، 3:2، 16:9…)، إطار قص قابل للسحب بشبكة الأثلاث، تعديل الاستقامة مع ملء تلقائي، تدوير 90°، قلب أفقي وعمودي |
| **الإعدادات المسبقة** | 19 إعدادًا مدمجًا في 6 فئات مع معاينات حية، **شريط شدة** (0–200%)، حفظ إعداداتك الخاصة |
| **تلقائي** | تعريض وتباين ونقطتا الأبيض والأسود وتوازن الأبيض تلقائيًا من إحصاءات الصورة |
| **سير العمل** | تراجع وإعادة، اضغط مطولًا للمقارنة مع الأصل، مدرج تكراري RGB، تكبير بإصبعين، نسخ ولصق الإعدادات، تقييم بالنجوم وعلامات اختيار/رفض |
| **التصدير** | JPEG بحجم 2048 أو 3072 أو حتى 4096 بكسل مع اختيار الجودة، حفظ في `Pictures/LumaLab` أو مشاركة مباشرة |
| **اللغة** | واجهة كاملة بالعربية (مع دعم RTL) والإنجليزية |

كل التعديلات محفوظة كمستند `EditSettings` (JSON) لكل صورة، والصورة الأصلية لا تُعدَّل أبدًا.

## البنية

```
apps/lumalab-android/
├── core/   محرك معالجة الصور، Kotlin/JVM خالص قابل للاختبار بدون أندرويد
│   ├── EditSettings.kt     نموذج التعديلات غير الإتلافية + JSON + الاستيفاء (شدة الإعداد المسبق)
│   ├── Processor.kt        خط المعالجة: هندسة → تقليل تشويش → إزالة ضباب → توازن أبيض/تعريض (خطي) →
│   │                       درجات → منحنيات → HSL → أبيض وأسود → تدرج ألوان → وضوح/ملمس → حدة → تظليل → حبيبات
│   ├── Geometry.kt         تدوير، قلب، استقامة (bilinear مع ملء تلقائي)، قص
│   ├── ToneCurveLut.kt     منحنى تكعيبي رتيب (Fritsch–Carlson)
│   ├── AutoTone.kt, Histogram.kt, Presets.kt, EditHistory.kt
│   └── src/test/           22 اختبارًا للمحرك
└── app/    تطبيق أندرويد (Compose + Material 3)
    ├── data/               مكتبة محلية (نسخ الأصول + library.json)
    ├── image/              فك الترميز مع EXIF، المصغّرات، الحفظ في MediaStore والمشاركة
    └── ui/                 المكتبة، المحرر، اللوحات، منحنى الدرجات، إطار القص، المدرج التكراري
```

المعاينة تُرسم بدقة 1600 بكسل، وتنزل إلى 900 بكسل أثناء السحب حتى تبقى الاستجابة سريعة. أنصاف الأقطار المكانية
(الوضوح، الحدة…) تتناسب مع حجم الصورة، فتبدو المعاينة الصغيرة مثل التصدير الكامل.

## البناء

المتطلبات: JDK 17 و Android SDK (API 35).

```bash
cd apps/lumalab-android
./gradlew -p core test          # اختبارات محرك المعالجة (لا تحتاج Android SDK)
./gradlew :app:assembleDebug    # app/build/outputs/apk/debug/app-debug.apk
```

يبني سير عمل GitHub Actions (`.github/workflows/lumalab-android.yml`) ملفَّي APK للتصحيح (debug) والإصدار (release)
مع كل دفع، ويرفعهما كـ artifact باسم `lumalab-apks`. نسخة الإصدار موقّعة بمفتاح التصحيح لتكون قابلة للتثبيت مباشرة.
للنشر على المتجر استبدله بمفتاحك.

الحد الأدنى: Android 10 (API 29).

---

**English summary.** LumaLab is an original, clean-room Android photo editor modelled on the feature set of
Adobe Lightroom Mobile. It includes a library with albums and batch paste, light, color (HSL and grading), effects,
detail, crop and straighten, tone curves, presets with an amount slider, auto tone, undo and redo,
before/after compare, a histogram, and JPEG export or share. It contains no Adobe code or assets. The image engine
(`core/`) is pure Kotlin with unit tests. The app (`app/`) uses Jetpack Compose, with Arabic and English UIs.
