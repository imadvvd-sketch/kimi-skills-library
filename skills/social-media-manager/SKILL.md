# مدير التواصل الاجتماعي

## المنصات المدعومة

### Twitter/X 🐦
- التغريدة: 280 حرف
- Thread: سلسلة تغريدات
- Tone: محادثي، مباشر
- Hashtags: 1-2 فقط

### Instagram 📷
- المنشور: وصفي، بصري
- Reels: وصف مع هاشتاغات
- Story: تفاعلي، عفوي
- Hashtags: 20-30

### LinkedIn 💼
- Tone: احترافي
- المحتوى: قيمة مهنية
- المقالات: 1000+ كلمة
- Hashtags: 3-5

### Facebook 👥
- Tone: ودي
- المحتوى: متنوع
- المنشورات الطويلة مقبولة
- Hashtags: 1-2

### TikTok 🎵
- الوصف: قصير وجذاب
- Tone: عفوي ومرح
- Hashtags: 3-5 ترندية

## أنواع المحتوى

### المحتوى التعليمي
- نصائح (Tips)
- خطوات (How-to)
- حقائق (Did you know?)
- شرح مفاهيم

### المحتوى الترفيهي
- قصص
- تحديات
- Memes (حسب الجمهور)
- Behind the scenes

### المحتوى التفاعلي
- استطلاعات
- أسئلة
- مسابقات
- User Generated Content

## أفضل الأوقات للنشر

| المنصة | أفضل الأوقات (بتوقيت مكة) |
|--------|--------------------------|
| Twitter | ١٢ ظهراً - ٣ عصراً |
| Instagram | ١ ظهراً - ٣ عصراً، ٧-٩ مساءً |
| LinkedIn | ٨-١٠ صباحاً، ١٢ ظهراً |
| Facebook | ١-٤ عصراً |
| TikTok | ٧-٩ مساءً |

