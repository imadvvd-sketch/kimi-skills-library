# موقع المكتبة الرئيسية للمطالعة العمومية لولاية أم البواقي

موقع ثابت (static) ثنائي اللغة: **العربية** (من اليمين إلى اليسار) على الرابط `/`، و**الفرنسية** (من اليسار إلى اليمين) على الرابط `/fr/`.
يضم مشاهد ثلاثية الأبعاد تفاعلية مبنية بالكود، بدون أي ملفات نماذج خارجية:

- **القسم الرئيسي:** كتاب مفتوح تتقلب صفحاته، وتطفو منه حروف عربية وأمازيغية (تيفيناغ) وذرات ضوئية. يميل المشهد مع حركة الفأرة، وينغلق الكتاب تدريجياً مع النزول في الصفحة.
- **قسم الخدمات:** رف خشبي عليه ستة كتب، كل كتاب يمثّل خدمة. عند المرور بالفأرة أو اللمس أو التركيز بلوحة المفاتيح يبرز الكتاب ويدور ويظهر اسم الخدمة.

**التقنيات:** Vite، وReact، وReact Three Fiber مع three.js، وFramer Motion، وTailwind CSS 4.

---

## 1. التشغيل على جهازك

**المتطلبات:** [Node.js](https://nodejs.org) الإصدار 20 أو أحدث (يُنصح بالإصدار 22).

```bash
cd oum-el-bouaghi-library
npm install        # مرة واحدة فقط: تثبيت المكتبات
npm run dev        # تشغيل خادم التطوير
```

افتح في المتصفح:

- النسخة العربية: <http://localhost:5173/>
- النسخة الفرنسية: <http://localhost:5173/fr/>

كل تعديل تحفظه يظهر فوراً في المتصفح.

### البناء والمعاينة

```bash
npm run build      # يُنتج الموقع النهائي في مجلد dist/
npm run preview    # معاينة النسخة النهائية على http://localhost:4173/
```

أمر `build` لا يكتفي بتجميع الملفات، بل يقوم أيضاً بما يلي:

- يولّد محتوى الصفحتين مسبقاً داخل ملفات HTML (prerender)، فيظهر النص فوراً ولمحركات البحث قبل تحميل JavaScript.
- يولّد `sitemap.xml` و`robots.txt` تلقائياً.
- يحقن وسوم SEO وOpen Graph وبيانات Schema.org.

## 2. أين أعدّل ماذا؟

### أ) المعلومات الحقيقية (الأهم): `src/data/siteInfo.js`

كل المعلومات العملية مجمّعة في هذا الملف: رابط الموقع، والاسم، والعنوان، والهاتف، والفاكس، والبريد، وأوقات العمل، والإحداثيات، وروابط التواصل، والأرقام، وسنة الافتتاح.

- **النصوص المؤقتة:** كل قيمة بين معقوفين مثل `[رقم الهاتف]` نص مؤقت. يظهر في الموقع **بخلفية ذهبية خفيفة** حتى لا تنساه، وتختفي الخلفية حين تضع القيمة الحقيقية.
- **أوقات العمل:** بالصيغة التالية:
  ```js
  openingHours: [
    { days: ['Sunday', 'Monday', 'Tuesday', 'Wednesday', 'Thursday'], opens: '08:30', closes: '17:00' },
    { days: ['Saturday'], opens: '09:00', closes: '13:00' },
  ],
  ```
  أسماء الأيام تُكتب بالإنجليزية كما في المثال، والموقع يترجمها تلقائياً. الأيام المتتالية تُعرض بصيغة «الأحد إلى الخميس».
- **الخريطة:** ضع الإحداثيات بهذه الصيغة: `geo: { lat: 35.87, lng: 7.11 }`. يمكنك أخذها من خرائط Google: انقر بالزر الأيمن على موقع المكتبة، فتظهر الإحداثيات. عندها تظهر خريطة OpenStreetMap تلقائياً، وهي مجانية ولا تحتاج مفتاحاً.
- **روابط التواصل:** ضع الرابط الكامل الذي يبدأ بـ `https://`. الرابط غير المكتمل يظهر باهتاً وغير قابل للنقر.
- **رابط الموقع:** بعد النشر عدّل `siteUrl` إلى الرابط النهائي، لأنه يُستعمل في الـ sitemap ووسوم المشاركة.
- **Schema.org:** بيانات Schema.org تُولَّد تلقائياً من هذا الملف. **لا تُضاف إليها إلا القيم المكتملة**، فأوقات العمل مثلاً تظهر فيها فقط بعد كتابتها بصيغة `HH:MM` صحيحة.

### ب) باقي البيانات: `src/data/`

| الملف | المحتوى | ملاحظات |
|---|---|---|
| `events.js` | الأنشطة والفعاليات | الفعاليات الحالية **أمثلة توضيحية** عليها `isSample: true` وتظهر عليها شارة «مثال توضيحي». احذفها وأضف فعالياتك بنفس الصيغة. |
| `services.js` | الخدمات الست | `color` هو لون كعب الكتاب على الرف ثلاثي الأبعاد. |
| `branches.js` | المكتبات الملحقة في البلديات | إن جعلت القائمة فارغة `[]` يختفي القسم ورابطه من القائمة تلقائياً. |
| `catalog.js` | الرصيد الوثائقي التجريبي | العناوين حقيقية، أما الرموز وحالة التوفر فوهمية. |

**ربط البحث بنظام فهرسة حقيقي** (مثل Koha أو PMB): عدّل الدالة `searchCatalog` في `src/lib/search.js` لتستدعي واجهة API الخاصة بالنظام، مع الإبقاء على نفس شكل النتائج.

### ج) نصوص الواجهة: `src/i18n/ar.js` و`src/i18n/fr.js`

كل النصوص الظاهرة موجودة في هذين الملفين: القائمة، والعناوين، والرسالة الترحيبية، ونبذة «عن المكتبة»، وأزرار البحث، وغيرها. وتشمل أيضاً عنوان الصفحة ووصفها لمحركات البحث في الجزء `seo`.

### د) الألوان والخطوط: `src/styles/index.css`

**الألوان:** في الكتلة `@theme` في أعلى الملف:

```css
--color-paper: #f5eddc;   /* الخلفية (ورق عتيق) */
--color-ink: #2e2116;     /* النص */
--color-brown: #7a5230;   /* البني الدافئ */
--color-olive: #566b2e;   /* اللون المميز (زيتوني) */
```

**الخطوط:** Amiri للعناوين، وTajawal للنصوص، وNoto Sans Tifinagh للحروف الأمازيغية. هي خطوط Google نفسها، لكنها **مستضافة داخل الموقع** عبر حزم `@fontsource`، فهي أسرع ولا تعتمد على خوادم Google. لتغيير خط: ثبّت الحزمة المقابلة، مثلاً `npm i @fontsource/cairo`، ثم عدّل أسطر `@import` و`--font-display` / `--font-body`.

### هـ) الصور والشعار

| العنصر | المكان |
|---|---|
| الشعار | `src/components/Logo.jsx` (شعار مؤقت بصيغة SVG). لاستعمال الشعار الرسمي ضع الملف في `public/logo.svg` واستبدل محتوى المكوّن بـ `<img src="/logo.svg" alt="" className={className} />` |
| أيقونة المتصفح | `public/favicon.svg` |
| صورة المشاركة (فيسبوك، واتساب…) | `public/og-image.jpg` بمقاس **1200×630** بكسل |
| الرسم البديل للكتاب (يظهر بدل المشهد ثلاثي الأبعاد) | `src/components/HeroIllustration.jsx` |
| أيقونات الخدمات والتواصل | `src/components/Icon.jsx` |

### و) المشاهد ثلاثية الأبعاد: `src/three/`

- `HeroScene.jsx`: إعدادات الكتاب الرئيسي. الكائن `TIERS` يحدد عدد الذرات والحروف لكل نوع جهاز.
- `Book.jsx`: شكل الكتاب وسرعة تقليب الصفحات عبر `period` و`duration`.
- `lib/textures.js`: الحروف الطائرة في المصفوفة `GLYPHS` وشكل الصفحات.
- `ShelfScene.jsx`: رف الخدمات.

## 3. الأداء وسهولة الوصول

**ثلاثة مستويات حسب الجهاز** تُحدَّد تلقائياً في `src/hooks/useDeviceTier.js`:

| المستوى | الأجهزة | ما يُعرض |
|---|---|---|
| كامل | الحواسيب | المشهد كاملاً بـ 60 إطاراً في الثانية |
| مخفف | الهواتف والأجهزة المتوسطة | ذرات أقل، ودقة أقل، و30 إطاراً في الثانية. المشهد لا يُحمَّل إلا بعد أول تفاعل (لمس أو تمرير) حتى لا يبطئ فتح الصفحة |
| ثابت | الأجهزة الضعيفة، أو بدون WebGL، أو مع «توفير البيانات»، أو مع تفعيل **تقليل الحركة** (`prefers-reduced-motion`) | رسم ثابت بدون أي حركة. ملفات 3D لا تُحمَّل إطلاقاً |

- **مكتبة 3D** في ملف منفصل (نحو 240KB مضغوطة) لا يُحمَّل إلا عند الحاجة. التحميل الأول نحو 120KB من JavaScript.
- **إيقاف الرسم:** المشاهد تتوقف عن الرسم حين تخرج من الشاشة.
- **لتجربة المستويات** أضف إلى الرابط: `?3d=full` أو `?3d=lite` أو `?3d=off`.
- **سهولة الوصول:** تنقّل كامل بلوحة المفاتيح، ورابط «تخطَّ إلى المحتوى»، وتباين ألوان وفق WCAG AA، ونصوص بديلة، ومعلومات الخدمات موجودة في بطاقات نصية وليس في المشهد فقط.

**نتائج Lighthouse عند التسليم:**

- **الهاتف:** أداء 90–93.
- **سهولة الوصول وأفضل الممارسات وSEO:** 100 للنسختين.
- **فحص axe:** 0 أخطاء.

## 4. تحسين محركات البحث (SEO)

- **صفحة لكل لغة** بعنوان ووصف خاصين، وبينهما وسوم `hreflang`.
- **وسوم Open Graph وTwitter** للمشاركة.
- **بيانات منظمة** من نوع `Library` (الاسم، والعنوان، والهاتف، وأوقات العمل، والإحداثيات) تُولَّد من `siteInfo.js`. يمكنك التحقق منها بعد النشر في [Rich Results Test](https://search.google.com/test/rich-results).
- **`sitemap.xml` و`robots.txt`** يُولَّدان عند البناء من `siteUrl`.
- **بعد النشر** أضف الموقع إلى [Google Search Console](https://search.google.com/search-console) وأرسل رابط `sitemap.xml`.

## 5. النشر على Netlify خطوة بخطوة

### الطريقة 1 (موصى بها): الربط بـ GitHub مع نشر تلقائي عند كل تعديل

1. ادخل إلى <https://app.netlify.com> وأنشئ حساباً مجانياً، ويمكنك الدخول بحساب GitHub مباشرة.
2. اضغط **Add new project** ثم **Import an existing project**.
3. اختر **GitHub** واسمح لـ Netlify بالوصول، ثم اختر المستودع `kimi-skills-library`.
4. في صفحة الإعدادات:
   - **Branch to deploy:** الفرع الذي فيه الموقع، مثل `main` بعد دمج التعديلات.
   - **Base directory:** `oum-el-bouaghi-library` ← **مهم جداً** لأن الموقع داخل مجلد فرعي.
   - **Build command** و**Publish directory:** تُقرأ تلقائياً من `netlify.toml`، وقيمتهما `npm run build` و`dist`.
5. اضغط **Deploy**. بعد دقيقة أو اثنتين يصبح الموقع متاحاً على رابط مثل `https://random-name.netlify.app`.
6. **غيّر اسم الموقع:** من **Project configuration ← Change project name**، مثلاً `bibliotheque-oum-el-bouaghi`.
7. **حدّث الرابط:** عدّل `siteUrl` في `src/data/siteInfo.js` إلى الرابط النهائي، ثم احفظ وادفع التعديل إلى GitHub (commit ثم push). Netlify يعيد النشر تلقائياً.
8. **(اختياري) نطاق خاص** مثل `bibliotheque-oeb.dz`: من **Domain management ← Add a domain** واتبع التعليمات. شهادة HTTPS مجانية وتلقائية.

بعدها: كل تعديل تدفعه إلى الفرع يُنشر تلقائياً خلال دقائق.

### الطريقة 2: السحب والإفلات بدون GitHub

1. على جهازك نفّذ:
   ```bash
   cd oum-el-bouaghi-library
   npm install
   npm run build
   ```
2. افتح <https://app.netlify.com/drop>.
3. اسحب المجلد `dist` بالكامل وأفلته في الصفحة.

ملف `public/_headers` (ترويسات الأمان والتخزين المؤقت) يُنسخ داخل `dist` ويعمل مع هذه الطريقة أيضاً. لكن عليك إعادة البناء والإفلات يدوياً عند كل تعديل.

### النشر على Vercel (بديل)

1. في <https://vercel.com> اختر **Add New… ← Project** واستورد المستودع.
2. **Root Directory:** `oum-el-bouaghi-library`. الإطار Vite يُكتشف تلقائياً.
3. اضغط **Deploy**.

ملاحظة: ملف `_headers` خاص بـ Netlify. على Vercel تُضبط الترويسات عبر ملف `vercel.json` عند الحاجة.

## 8. حل المشكلات الشائعة

- **`npm install` يفشل:** تأكد من إصدار Node بالأمر `node -v`، يجب أن يكون 20 أو أحدث.
- **المشهد ثلاثي الأبعاد لا يظهر:** قد يكون جهازك في المستوى «ثابت»، أو أن «تقليل الحركة» مفعّل في نظامك. جرّب إضافة `?3d=full` إلى الرابط.
- **Netlify يبني المستودع بالخطأ:** تحقق من أن **Base directory** هو `oum-el-bouaghi-library`.
- **الخريطة لا تظهر:** تأكد أن `lat` و`lng` أرقام بدون علامات تنصيص.
