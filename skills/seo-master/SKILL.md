# SEO Master - خبير تحسين محركات البحث

## 1. بحث الكلمات المفتاحية (Keyword Research) 🔍

### سير العمل
1. حدد Seed Keywords (الكلمات الأساسية للنشاط)
2. وسع القائمة بـ Long-tail Keywords
3. حلل نية البحث (Search Intent):
   - Informational (معلوماتية)
   - Navigational (تنقلية)
   - Transactional (تجارية)
4. تحقق من صعوبة الكلمة (Keyword Difficulty)
5. تحلل المنافسين

### أدوات البحث
- Google Keyword Planner
- Ubersuggest
- AnswerThePublic
- Google Trends

### قالب تحليل
```
الكلمة المفتاحية | حجم البحث | الصعوبة | النية | الأولوية
-------------------|-----------|----------|-------|----------
مثال كلمة        | 1000/شهر | متوسط   | معلوماتية | عالية
```

## 2. On-Page SEO 📝

### العنوان (Title Tag)
- 50-60 حرف كحد أقصى
- الكلمة المفتاحية في البداية
- جذاب ووعد واضح
- فريد لكل صفحة

### الوصف (Meta Description)
- 150-160 حرف
- دعوة للعمل (CTA)
- تضمين الكلمة المفتاحية

### هيكل المحتوى
```
H1: عنوان رئيسي واحد فقط (يحتوي الكلمة المفتاحية)
├── H2: عنوان فرعي
│   ├── H3: نقطة تفصيلية
│   └── H3: نقطة تفصيلية
├── H2: عنوان فرعي
└── H2: الخلاصة
```

### عناصر On-Page الأساسية
| العنصر | الإرشاد |
|--------|---------|
| URL Slug | قصير، وصفي، يحتوي الكلمة |
| Alt Text | وصفي، يتضمن الكلمة |
| Internal Links | 2-3 روابط داخلية |
| External Links | 1-2 روابط لمصادر موثوقة |
| Schema Markup | مناسب لنوع المحتوى |

## 3. Technical SEO ⚙️

### Core Web Vitals (2026)
| المقياس | الهدف | الوصف |
|---------|-------|-------|
| LCP | < 2.5s | سرعة تحميل المحتوى الرئيسي |
| INP | < 200ms | استجابة التفاعل |
| CLS | < 0.1 | استقرار التخطيط البصري |

### قائمة المراجعة التقنية
- [ ] Mobile-First Indexing متوافق
- [ ] HTTPS مفعل
- [ ] XML Sitemap محدث
- [ ] robots.txt صحيح
- [ ] Canonical URLs
- [ ] Schema Markup صالح
- [ ] لا يوجد روابط معطلة
- [ ] لا يوجد محتوى مكرر
- [ ] JavaScript يُعرض بشكل صحيح
- [ ] Structured Data خالٍ من الأخطاء

### Schema Markup أنواع
- Article / BlogPosting
- Product (مع offers, reviews)
- FAQPage
- HowTo
- LocalBusiness
- Organization
- BreadcrumbList

## 4. Off-Page SEO 🔗

### بناء الروابط (Link Building)
- **الروابط الطبيعية**: محتوى يستحق الاقتباس
- **Guest Posting**: كتابة في مواقع أخرى
- **Broken Link Building**: إصلاح روابط معطلة
- **Skyscraper Technique**: تحسين المحتوى الموجود
- **Digital PR**: تغطية إعلامية

### E-E-A-T (2026)
| العنصر | التطبيق |
|--------|---------|
| Experience | دراسات حالة، نتائج حقيقية |
| Expertise | سيرة الكاتب، شهادات |
| Authoritativeness | روابط من مصادر موثوقة |
| Trustworthiness | مراجعات، HTTPS، سياسات واضحة |

## 5. Local SEO 🗺️

### تحسين Google Business Profile
- [ ] المعلومات كاملة ومحدثة
- [ ] الصور عالية الجودة
- [ ] الرد على المراجعات
- [ ] المنشورات المنتظمة
- [ ] الأسئلة والأجوبة

### NAP Consistency
- الاسم (Name) + العنوان (Address) + الهاتف (Phone)
- متطابق عبر جميع المنصات

## 6. تحليل المنافسين 🕵️

### خطوات التحليل
1. حدد 3-5 منافسين رئيسيين
2. حلل الكلمات المفتاحية التي يتصدرونها
3. حدد فجوات المحتوى (Content Gaps)
4. حلل روابطهم الخلفية
5. راقب أداءهم

### قالب تحليل
```
المنافس | الكلمات | الروابط | نقاط القوة | نقاط الضعف
---------|---------|---------|------------|------------
موقع 1  | 500     | 2000    | محتوى عميق | بطيء
```

## 7. AI Search Optimization 🤖

### تحسين للبحث بالذكاء الاصطناعي
- **Structured Data دقيق**: AI يعتمد على Schema
- **محتوى مباشر**: أجب بشكل مباشر على الأسئلة
- **FAQ Schema**: للأسئلة الشائعة
- **HowTo Schema**: للخطوات التعليمية
- **روبوتس**: السماح لـ OAI-SearchBot

## نصائح ذهبية 🏆

1. **المحتوى أولاً**: أفضل SEO هو محتوى يستحق المشاركة
2. **الصبر مفتاح**: النتائج تستغرق 3-6 أشهر
3. **تحديث مستمر**: حدث المحتوى القديم
4. **ركز على المستخدم**: لا على محركات البحث
5. **قياس دائم**: Google Search Console + Analytics
