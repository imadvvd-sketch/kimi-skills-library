# محسّن SEO

## سير العمل

### 1. البحث عن الكلمات المفتاحية 🔍
- حدد موضوع المحتوى
- اكتشف الكلمات المفتاحية الرئيسية والفرعية
- حلل نية البحث (Informational, Navigational, Transactional)
- تحقق من الكلمات المنافسة

### 2. On-Page SEO 📝
- عنوان (Title): 50-60 حرف مع الكلمة المفتاحية
- وصف ميتا (Meta Description): 150-160 حرف
- عناوين H1, H2, H3 مع الكلمات المفتاحية
- روابط داخلية وخارجية
- نسبة الكلمة المفتاحية (1-2%)

### 3. هيكل المقال
```
H1: العنوان الرئيسي (مع الكلمة المفتاحية)
├── مقدمة جذابة
├── H2: ما هو [الموضوع]؟
│   ├── شرح مفصل
│   └── H3: نقطة فرعية
├── H2: لماذا [الموضوع] مهم؟
│   ├── فائدة ١
│   └── فائدة ٢
├── H2: كيفية [الموضوع]
│   ├── خطوة ١
│   └── خطوة ٢
├── H2: نصائح وأفضل الممارسات
├── H2: الخلاصة
└── CTA (Call to Action)
```

## معايير الجودة

### المحتوى
- فريد ومفيد
- طول 1500+ كلمة للمقالات التنافسية
- فقرات قصيرة (3-4 أسطر)
- قوائم نقطية
- صور مع alt text

### التقني
- عنوان URL قصير ووصفي
- روابط داخلية ذات صلة
- سرعة التحميل
- توافق الجوال

## أدوات
- تحليل الكلمات المفتاحية
- فحص On-Page
- تحليل المنافسين
- تتبع التصنيفات

## تحذيرات
- لا حشو كلمات مفتاحية (Keyword Stuffing)
- لا محتوى مكرر
- لا روابط خلفية (Backlinks) م buying
- ركز على المستخدم أولاً
