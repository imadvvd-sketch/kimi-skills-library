# مكتبة مهارات Kimi 🧠

> مجموعة شاملة من المهارات (Skills) الجاهزة لتوسيع قدرات Kimi AI وتخصيصه لمجالات متنوعة.

## ما هي مهارات Kimi؟

**المهارات (Skills)** هي حزم معرفية معيارية تمكّن Kimi من أداء مهام متخصصة بكفاءة عالية. كل مهارة تحتوي على:

- 📋 **إرشادات عملية** - خطوات واضحة لأداء المهمة
- 🔧 **أدوات ونصوص** - سكربتات ومراجع جاهزة للاستخدام
- 🎯 **خبرة مجالية** - معرفة متخصصة في مجال معين

## هيكل المهارة

```
skill-name/
├── SKILL.md          # ملف الإرشادات الرئيسي (إجباري)
├── scripts/          # سكربتات وبرامج (اختياري)
├── references/       # مراجع وتوثيق (اختياري)
└── assets/           # قوالب وملفات مساعدة (اختياري)
```

## كيفية الاستخدام 🚀

### الطريقة الأولى: التحميل المباشر
1. حمّل ملف `.skill` الخاص بالمهارة
2. أرفقه في محادثتك مع Kimi
3. اطلب المهمة التي تريدها

### الطريقة الثانية: الاستنساخ
```bash
git clone https://github.com/imadvvd-sketch/kimi-skills-library.git
```

### الطريقة الثالثة: نسخ المحتوى
انسخ محتوى ملف `SKILL.md` من أي مهارة والصقه في محادثتك مع Kimi.

## كيفية إنشاء مهارة جديدة ✨

1. انسخ مجلد `skill-template/` كقالب
2. عدّل ملف `SKILL.md` بمحتوى المهارة الجديدة
3. أضف سكربتات ومراجع حسب الحاجة
4. استخدم `package_skill.py` لحزم المهارة
5. أرسل Pull Request لمشاركتها مع الجميع!
